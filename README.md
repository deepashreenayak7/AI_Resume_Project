# AI Resume Screening System

This is a Streamlit-based AI Resume Screening & Job Recommendation app.  

## Features
- Upload Resume PDF
- Upload or paste Job Description
- Automatic skill extraction
- ATS score calculation
- Matched/missing skills detection
- Skill gap dashboard with colored bars
- Resume improvement suggestions

## Requirements
- Python 3.8+
- Streamlit
- pdfplumber
- pandas
- scikit-learn
- altair
